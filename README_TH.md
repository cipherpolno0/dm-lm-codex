# ระบบฐานข้อมูลคณะสงฆ์และการศึกษา

เว็บไซต์จาก `dm_lm_codex.zip` ใช้ข้อมูลสมมติเท่านั้น รองรับการค้นหาทำเนียบตามวันที่ ดูลำดับหน่วยงาน ทะเบียนบุคคล ประวัติตำแหน่ง และแบบจำลองฐานข้อมูล 33 ตาราง

## เริ่มใช้งาน

เปิด `index.html` โดยตรงเพื่ออ่านและค้นหาแบบออฟไลน์

หากต้องการเพิ่มและบันทึกข้อมูล ต้องมี Node.js 22 ขึ้นไป แล้วรัน:

```bash
npm start
```

หรือเปิด `start.bat` บน Windows / `./start.sh` บน macOS และ Linux ไม่ต้องติดตั้ง dependency

1. เปิด http://127.0.0.1:8082
2. เข้า “จัดการข้อมูลสมมติ” และใส่รหัสที่ Terminal แสดง
3. เพิ่มหน่วยงาน บุคคล หรือประวัติตำแหน่ง
4. กด “เผยแพร่ทำเนียบ” เพื่อค้นหาข้อมูลที่เพิ่มจากหน้าทำเนียบ

ข้อมูลบันทึกใน `data/portal-state.json` และคงอยู่เมื่อเปิดตัวรันใหม่ ไฟล์นี้ถูกยกเว้นจาก Git เพื่อป้องกันการอัปโหลดข้อมูลที่เพิ่มบนเครื่อง ใช้ปุ่มสำรอง JSON เพื่อเก็บสำเนา รหัสจัดการเปลี่ยนเมื่อเริ่มตัวรันใหม่ เซสชันมีอายุ 60 นาที ตัวรันรับการเชื่อมต่อเฉพาะเครื่องนี้

## ขอบเขตของ repository รุ่นนี้

มีหน้าเว็บ ตัวรัน ข้อมูลสมมติ โมดูลต้นฉบับที่ตัวรันเรียกใช้ และชุดทดสอบ รวมทั้ง README และคำสั่ง npm

เอกสาร Word/Excel, ZIP ต้นฉบับ, เอกสารด้านความปลอดภัย/UAT/ปฏิบัติการ และโมดูลที่เว็บไซต์ยังไม่ได้ใช้ ยังไม่ได้เผยแพร่ใน repository สาธารณะนี้ หน้าเว็บจึงไม่มีข้อความหรือไฟล์ต้นฉบับเหล่านั้นฝังอยู่ ชุด ZIP ที่ส่งมอบก่อนหน้านี้ยังคงเป็นชุดเต็ม

ใช้ JSON บนเครื่องเป็นที่เก็บข้อมูล ยังไม่ได้เชื่อม PostgreSQL/Prisma จริง การเผยแพร่ทำเนียบเป็นการเผยแพร่ข้อมูลสมมติบนเครื่อง ไม่มีผลเป็นการแต่งตั้งหรือประกาศทางการ
